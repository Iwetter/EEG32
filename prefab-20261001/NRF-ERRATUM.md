# nRF52832 erratum 138 — implementation and lot gate

Revision 2.1 grounds U1 package pin 37 (P0.25) and pin 38 (P0.26) directly to the existing exposed VSS pad, using two 0.1524 mm front-copper tracks. Both pins were unused and explicitly NC in 2.0. No acquisition GPIO, RF matching part, crystal part, package land or existing route changed.

Nordic's current erratum 138 pages cover QFAA build codes Bx0 (revision 1), Ex0 (revision 2) and Gx0 (revision 3). The published remedy is reference schematic/layout 1.1 or later. Nordic's verified technical-support answer permits unused P0.25/P0.26 to connect directly to the center pad instead of adding the reference design's 12 pF capacitors. This implementation follows that unused-pin guidance. [Revision 1](https://docs.nordicsemi.com/r/bundle/errata_nrf52832_rev1/page/err/nrf52832/rev1/latest/anomaly_832_138.html), [revision 2](https://docs.nordicsemi.com/r/bundle/errata_nrf52832_rev2/page/err/nrf52832/rev2/latest/anomaly_832_138.html), [revision 3](https://docs.nordicsemi.com/r/bundle/errata_nrf52832_rev3/page/err/nrf52832/rev3/latest/anomaly_832_138.html), [Nordic unused-pin answer](https://devzone.nordicsemi.com/f/nordic-q-a/18476/errata-138---spurious-emission-on-gpio-exceeds-limits-in-radiated-tests).

**Exact purchased silicon revision is still unconfirmed.** NRF52832-QFAA-R specifies the ordering part/package and packing; it does not establish the build code of the delivered lot. The local footprint name ending in `R7` is not silicon-revision evidence. Before releasing an assembly lot, record its reel label, package marking/build code, supplier traceability and a first-article FICR INFO.PART / INFO.VARIANT readback. Match these to Nordic's revision identification and audit the applicable firmware errata. Do not infer the delivered revision from the BOM.

Firmware must leave P0.25 and P0.26 unused, with no driven-high output, pull-up, peripheral PSEL assignment or test toggling. They are physical ground connections. Review bootloader, application, reset and test-image configuration. No firmware source exists in this hardware checkpoint, so this requirement is documented rather than implemented in software.

The two remaining ERC warnings are `pin_to_pin`: a bidirectional GPIO is connected to the GND power-output flag. They are the intentional, documented unused-pin connections; symbol pin types and ERC checks remain intact. Final DRC and physical connectivity checks verify both pins reach U1.49. Conduct radiated testing with BLE RX/TX active; a hardware workaround does not itself constitute RF certification.
